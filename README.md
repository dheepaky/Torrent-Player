## ✨ Features

- ⚡ **Instant In-Memory Streaming**: Video chunks buffer into RAM via WebRTC—watch immediately without waiting for full downloads.
- 📱 **Mobile-First Experience**: Touch gestures (left: brightness, right: volume), double-tap seek, and auto-hiding navigation.
- 🔊 **300% Audio Booster**: Amplify quiet audio tracks directly in the browser via Web Audio API.
- 💬 **Multi-Format Subtitles**: Automatic subtitle extraction with support for external `.srt` / `.vtt` drag & drop.
- 📺 **External Player Hand-off**: Open streams in VLC, IINA, MPV, PotPlayer, or export `.m3u` playlists.
- 💾 **Native Android Downloader**: Save files directly to mobile `/Downloads` folder via native MediaStore integration.
- 🔒 **100% Client-Side Privacy**: No media, logs, or analytics ever touch any centralized server.

## 🚀 Quick Start

```bash
# Clone and install dependencies
git clone https://github.com/dheepaky/Torrent-Player.git
cd Torrent-Player
npm install

# Start development server
npm run dev

# Build production web bundle
npm run build

# Run desktop app (Electron)
npm run electron:dev
```

## ⌨️ Player Shortcuts & Gestures

| Action | Desktop Shortcut | Mobile Gesture |
| :--- | :--- | :--- |
| **Play / Pause** | `Space` or `k` | Single Tap |
| **Seek ±10s** | `j` / `l` or `←` / `→` | Double-Tap Left / Right |
| **2× Fast-Forward** | Press & Hold Video | Press & Hold Screen |
| **Brightness** | — | Swipe Up/Down (Left 50%) |

| **Fullscreen** | `f` | Rotate / Fullscreen Button |
