Torrent Player

Stream Magnet Links & Torrents Directly in Your Web Browser

Instant Peer-to-Peer Video Playback

Torrent Player is a browser-based media streaming application powered by WebTorrent and WebRTC. Paste any magnet link, 40-character info hash, or drag-and-drop a .torrent file to start watching immediately without downloading full files or installing third-party torrent clients.

  • ⚡ Zero Installation: Runs completely inside modern web browsers.
  • 🔒 100% Private: Decentralized peer-to-peer data channels with zero server storage.
  • 🔊 Audio Booster: Amplify low audio levels up to 300% via Web Audio API.
  • 💬 Subtitle Support: Synchronized playback with drag-and-drop .srt and .vtt files.
  • 📺 Desktop Handoff: One-click launch in VLC, IINA, MPV, or PotPlayer.

How to Stream in 3 Steps

  1. Copy Link: Obtain a magnet link or .torrent file.
  2. Paste into Stream Bar: Input your magnet URI or drop the file onto the player.
  3. Enjoy Playback: Video buffers and plays sequentially in high quality.
